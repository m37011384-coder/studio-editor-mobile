# Studio Editor Mobile

A mobile-optimized HTML mockup inspired by Roblox Studio, built with HTML, CSS, and Three.js.

## Features
- Dark Studio-like UI
- Explorer panel
- Properties panel
- 3D viewport with Three.js
- Touch-friendly mobile layout
- Add blocks, spheres, lights, and cameras
- Simple selection and transform controls

## Run locally
Open `index.html` in a browser, or serve the folder with a tiny local server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Stack
- HTML
- CSS
- JavaScript
- Three.js

## Notes
This is a visual editor-style prototype designed to feel similar to Roblox Studio while staying optimized for phone screens.
